# Jadenzaleski Tap

## How do I install these formulae?

`brew install jadenzaleski/tap/<formula>`

Or `brew tap jadenzaleski/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jadenzaleski/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
